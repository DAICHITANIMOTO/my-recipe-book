# 自動レシピ生成手順（夜間エージェント用）

毎晩1回、クラウドの定期エージェントがこの手順を実行する。
手動セッションで「未処理の写真をレシピにして」と言われたときも同じ手順を使う。

## 前提

- 作業ブランチは `main`。PRは作らず `main` に直接 commit / push する。
- 受信箱は `recipes/inbox/`。ここにある**画像ファイル**（.jpg / .jpeg / .png / .heic / .webp）が処理対象。
  `README.md` は無視する。
- 画像と同じ名前の `.txt`（例: `2026-09-06_193000.txt`）があれば「ヒント」として使う。中身の例:
  ```
  料理名: ガスパチョ
  店名: バルさくら
  日付: 2026-09-06
  ```
  どの行も欠けていてよい。

## 手順

1. `recipes/inbox/` の画像を一覧する（`README.md` は数えない）。1枚も無ければ**何もせず終了**（commitもしない）。

2. 画像を1枚ずつ処理する。各画像について:

   a. `Read` で画像の内容を見る。

   b. ヒント `.txt` があれば読む。無い項目は次のように補う:
      - 料理名: 写真から推定（例: 「オムライス」「アヒージョ」）
      - 店名: 不明なら空欄
      - 日付: ヒントに無ければ「今日の日付」（`date +%Y-%m-%d`）

   c. ファイル名の土台を決める: `YYYY-MM-DD_料理名`
      - 料理名は日本語、スペースと `/` は使わない
      - 同名の `recipes/*.md` が既にあれば末尾に `_2`、それも有れば `_3` …

   d. 画像を移動する:
      `git mv recipes/inbox/<元ファイル> recipes/画像/<土台>.<元の拡張子>`
      ヒント `.txt` があれば `git rm` で削除する。

   e. `recipes/<土台>.md` を `レシピ雛形.md` をベースに作る。埋め方:
      - frontmatter: `title`=料理名 / `date`=日付 / `restaurant`=店名（不明なら空）/
        `category`=写真と料理名から推定（前菜／タパス／メイン／魚／肉／パスタ／スープ／サラダ／デザート など）
      - 本文1行目に固定で:
        `> ※この材料・作り方は写真と料理名からの推定です。実際に作って調整してください。`
      - 画像リンク: `![料理名](画像/<土台>.<拡張子>)`
      - `## 説明`: 写真とヒントから2〜4文
      - `## 材料（2人分）`: 写真と料理名から**推定**して分量つきで箇条書き
      - `## 作り方`: 写真と料理名から**推定**して番号付き手順
      - `## メモ・感想`: `（食べたときの感想をここに書く）` のまま
      - `## 調整メモ`: `（実際に作ってみて気づいたことをここに追記する）` のまま

3. 1件以上処理したら、まとめて commit して push する:
   ```
   git add -A
   git commit -m "レシピ追加（自動）: <作った料理名をカンマ区切り>"
   git push origin main
   ```

4. 最後に、処理した件数と作成したファイル名を一覧で出力する。

## エラー時

- 画像が壊れている / 中身を判別できない → その画像は `_未処理/` に残したまま、他の画像の処理を続ける。最後の出力で「スキップした」と報告する。
- `git push` が失敗した → エラー全文を出力して終了（次の晩に再試行される）。
