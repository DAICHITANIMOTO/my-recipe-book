# inbox（写真の受信箱）

スマホのショートカットからアップした料理写真は、まずこのフォルダに入る
（`_未処理` ではなく `inbox` なのは、ショートカットのURLに日本語が入ると
文字化けの原因になるため、英字にしている）。

毎晩1回、クラウドの定期エージェント（`build/自動レシピ生成手順.md`）が、
ここの画像を1枚ずつ:

1. 内容を見てレシピの下書きを作成（`recipes/日付_料理名.md`）
2. 画像を `recipes/画像/日付_料理名.拡張子` に移動
3. commit & push

処理が終わった画像はこのフォルダから消える（＝空なら「未処理なし」）。

画像といっしょに `同じ名前.txt`（例: `2026-09-06_193000.txt`）があれば、
そこに書かれた料理名・店名・日付を優先して使う。
